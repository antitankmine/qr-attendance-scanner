# qr-attendance-scanner

A simple android application that is used to check the attendance of students in small to large institutions. 

# Features
- Mass QR code generation for classes, only needing to input the student's name, and any unique number identifier. 
- Scan and go concept for students in campuses, Timestamp and present/absent and on-time or late identifiers
- Only stores necessary data on a separate server (located in your institution, of course)
- Only gate guards, administrators, and teachers have access to the app
- Easy access for teachers in checking student attendance record
- Different setup approaches for different sized institutions
